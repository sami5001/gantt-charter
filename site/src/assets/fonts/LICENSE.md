# Font licences

IBM Plex Sans and IBM Plex Mono, copyright IBM Corp., are used under the
SIL Open Font License 1.1 (https://opensource.org/licenses/OFL-1.1).

The TTF files in this directory are embedded into exported PDF files;
the matching woff2 files from @fontsource are embedded into exported SVG
and PNG files so the charts render identically everywhere.
